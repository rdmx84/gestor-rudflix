# Gestor Rudflix

Projeto Android gerado pelo **Web2APK Studio**.

- **URL de destino:** https://gestorv3.org/rudflix/control/home
- **Modo:** WebView Nativo (Kotlin)
- **Application ID:** `org.wikipedia.pocket`
- **Versão:** 1.0.0 (código 1)

---

## Opção 1: Gerar o APK na nuvem sem instalar nada (GitHub Actions)

1. Crie um repositório no GitHub (público ou privado).
2. Envie todos os arquivos deste ZIP para o repositório (`git init && git add . && git commit -m "Projeto Android" && git push`).
3. Abra a aba **Actions** no GitHub e clique em **Compilar APK Android** > **Run workflow** (ou aguarde o push automático).
4. Ao finalizar (~2 a 3 minutos), baixe o arquivo **`org.wikipedia.pocket-debug-apk`** na seção *Artifacts*.

---

## Opção 2: Compilar localmente no Android Studio

1. Abra o **Android Studio** > **Open** e selecione a pasta descompactada.
2. Aguarde a sincronização automática do Gradle.
3. Para testar no celular: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. Para publicar na Google Play Store: **Build > Generate Signed Bundle / APK > Android App Bundle (.aab)**.
